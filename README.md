# userscripts

Personal userscripts, run in Safari with the [Userscripts](https://github.com/quoid/userscripts) extension.

## youtube

- [`youtube-loop-button.user.js`](youtube/youtube-loop-button.user.js): adds a one-click loop toggle to the player controls, with a hover tooltip.

## Install

Open the Userscripts extension, create a new script, paste in the file's contents, and save.

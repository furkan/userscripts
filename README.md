# userscripts

Personal userscripts, run in Safari with the [Userscripts](https://github.com/quoid/userscripts) extension.

## youtube

- [`youtube-loop-button.user.js`](youtube/youtube-loop-button.user.js): adds a one-click loop toggle to the player controls, with a hover tooltip.

## reddit

- [`reddit-to-redlib.user.js`](reddit/reddit-to-redlib.user.js): redirects Reddit pages to the [Redlib](https://github.com/redlib-org/redlib) instance at `redlib.catsarch.com`.

## chatgpt

- [`chatgpt-bulk-delete.user.js`](chatgpt/chatgpt-bulk-delete.user.js): adds a "Bulk delete" button that opens a panel listing every conversation, including chats in Projects, with title, date and project filters, select-all and shift-click ranges, then deletes the selection in one go.

## Install

Open the Userscripts extension, create a new script, paste in the file's contents, and save.
